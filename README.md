# Rasel Rana — Personal Website

The source code of the personal website of **Rasel Rana**, Manager (Technical) at Bangladesh Telecommunications Company Limited (BTCL).

**Live site:** [raselrana.com.bd](https://raselrana.com.bd)

## About This Project

This is a personal project, built and maintained for my own website. The repository exists to keep the site's history and to deploy it; it is not a template or starter kit, and it is not intended to be cloned, reused or redistributed.

The site presents my professional background in telecommunications and electrical and electronic engineering: who I am, where I have worked, what I have achieved, and how to reach me.

## What the Site Includes

- **Portfolio pages** — Home, About, Journey, Experience, Achievements, Projects, Skills, Education and Publications.
- **Downloads** — my professional portfolio and contact card.
- **Contact** — a contact form that delivers messages to my inbox.
- **Blog** — writing published at `/blog`.
- **Private admin area** — lets me update the Achievements content without changing the code.
- **Light and dark themes** — follows the visitor's system setting, with a manual switch.
